# Getting Started

This section covers everything you need to know to start working with Claude on this prototyping project. No technical background is required. If you can describe a screen in plain English, you can work with Claude.

## In This Section

- [How to Work with Claude](./how-to-work-with-claude.md) — How to write requests, what to include, how the conversation flows, and what approval means in practice. Start here if you are new to the project.

- [What Claude Can Do](./what-claude-can-do.md) — A full list of Claude's capabilities: building screens, editing screens, reviewing flows, working with Figma, managing navigation, generating states, reviewing copy, and more. Also explains what Claude will never do without your explicit sign-off.

- [The Approval Model](./approval-model.md) — Explains the three levels of decision-making: what Claude handles automatically, what it prefills and confirms, and what always requires your explicit approval. Includes a table of common situations so you know what to expect.

## Quick Tips

- You do not need to use slash commands. Plain English works for everything.
- You can attach a screenshot or Figma link directly to your message.
- Claude will tell you if it needs more information before starting.
- Claude will never overwrite an existing screen without showing you a delta report first.
- If something looks wrong, just describe the correction — Claude will apply only what you approve.
