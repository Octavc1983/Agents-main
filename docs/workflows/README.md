# Workflows

This section contains step-by-step guides for the most common tasks in this project. Each guide is written for UX designers and PMs — no technical knowledge required.

## Workflow Guides

- [Create a New Screen](./create-a-new-screen.md) — How to ask Claude to build a brand-new prototype page, what to include in your request, what Claude creates automatically, and how to review the result.

- [Update an Existing Screen](./update-an-existing-screen.md) — How to describe a change to a screen that already exists, how the delta report works, and what Claude will and will not touch.

- [Review a Flow for UX Quality](./review-a-flow.md) — How to trigger a UX audit, what the review checks, how findings are categorized, and how to act on them.

- [Review Backend Edge Cases](./review-backend-edge-cases.md) — What backend edge cases mean in UX terms, how Claude detects them, and what a finding looks like.

- [Review and Update Navigation](./review-navigation.md) — How navigation is structured, how to add a new navigation item, how to sync a navigation screenshot, and what Claude protects.

- [Working with Figma or Screenshots](./work-with-figma-or-screenshots.md) — How to attach a Figma link or screenshot, what Claude extracts from each, and what "pixel perfect" requires.
