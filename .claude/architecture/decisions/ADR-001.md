# ADR-001: SVG-Only Icon System

## Status
Accepted

## Context
The prototype requires icons throughout the navigation sidebar, action menus, and feature pages. Icon libraries (FontAwesome, Heroicons, etc.) add dependency weight and produce inconsistent styling control.

## Decision
All icons must be inline SVG React components exported from `src/assets/icons/NavIcons.tsx`.

No icon libraries, PNG/JPG images, emoji, or icon fonts are permitted.

Each icon component must:
- Accept a `size` prop (default 24)
- Accept `className` and `style` props
- Use `stroke="currentColor"` or `fill="currentColor"` so color is inherited from CSS
- Have a consistent viewBox

## Consequences
- Icons are always the correct color when placed inside themed containers
- New icons require adding a component to `NavIcons.tsx` — this is intentional
- SVG paths must be traced from Figma or spec; no raster icon fallback is allowed

## Alternatives Considered
- Icon library: rejected due to dependency weight and styling overhead
- CSS mask-image SVG: rejected due to poor accessibility and complex theming
