# Deprecated Terms

## Purpose
Tracks terminology that has been retired, renamed, or replaced. Prevents deprecated terms from re-entering the product through generated pages, new features, or copy edits.

Also used during terminology reviews: any deprecated term found in a page triggers a required update before that page is shipped.

## Ownership
UX Writing / Product Design

## Status
Active — updated when terms are retired

## Update Rules
- Add a term here when it is retired from the terminology-registry
- Never delete entries — this is a permanent audit trail
- Include the replacement term and the reason for deprecation
- Include the date deprecated and the list of pages that need updating

## Entry Template
```markdown
### [Deprecated Term]
**Replaced by:** [new preferred term]
**Category:** [UI label / feature name / domain entity / action verb / status / navigation]
**Reason deprecated:** [why this term was retired]
**Deprecated on:** [YYYY-MM-DD]
**Pages requiring update:** [list pages that still use this term]
**Updated pages:** [list pages already updated]
```

## Review Requirements
- Before shipping a new page, grep for deprecated terms in all new UI text
- If a deprecated term is found, it must be replaced before the page is marked ready for review
